# Co2Co 편집기 변경 이력

## 2026-08-10

- V2 방향 수립: 상태 기반 멀티미디어 편집기
- 1~3페이지 구조 반영
- 객체 드래그/리사이즈 구조 반영
- 텍스트, 버튼, 이미지, 동영상, 음악, 섹션 객체 모델 반영
- 작업 계획, 팀 작업지시서, 고객용 매뉴얼, QA 체크리스트 문서화 시작

## 2026-08-10 V3

- V1의 프리미엄 다크 감각을 V2 상태 기반 편집기 위에 재반영
- ImageGen으로 생성한 프리미엄 편집기 히어로 이미지를 `assets/co2co-editor-hero.png`로 저장
- 첫 페이지 스타터 구성을 고급 상업용 편집기 콘셉트로 재설계
- 드래그 시작 시 undo 히스토리 저장 추가
- 드래그 중 전체 렌더링을 줄이고 선택 객체의 좌표만 즉시 갱신하도록 개선
- X/Y/W/H 입력값 clamp 처리 추가
- 큰 미디어로 localStorage 저장 실패 시 안내 메시지 표시

주의: 브라우저에 이전 편집 상태가 저장되어 있으면 새 V3 스타터 화면이 바로 보이지 않을 수 있다. 새 스타터를 보려면 브라우저 개발자 도구 또는 편집기 초기화 기능으로 localStorage의 `co2co-editor-v2` 상태를 삭제한다.

## 2026-08-10 V3.1

- 색상 팔레트 UI 추가: Studio, Ocean, Paper, Coral
- 페이지 배경색과 강조색을 직접 조절하는 기능 추가
- 팔레트 적용 시 페이지와 주요 객체의 색상이 함께 변하도록 처리
- 관계 정렬 기능 추가: 좌/중앙/우, 상/중/하
- 가로/세로 분배 기능 추가
- `함께조절` 기능 추가: 현재 페이지 테마를 기준으로 텍스트, 버튼, 섹션, 오디오 객체의 톤을 함께 조정
- 레이어 조절 기능 추가: 앞으로, 뒤로, 맨뒤

## 2026-08-10 V3.2

- 작업 문서와 고객 매뉴얼 백업을 docs/backups/20260810-095110에 저장
- 왼쪽 추가/페이지/레이어/테마 패널을 기본 숨김 상태의 떠오르는 패널로 변경

- 객체 선택 시 오른쪽 편집 패널이 자동으로 나타나고, 빈 캔버스 클릭 또는 Esc로 패널을 정리할 수 있도록 개선
