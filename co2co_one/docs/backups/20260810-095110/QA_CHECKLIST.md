# Co2Co 편집기 QA 체크리스트

## 페이지

- 1페이지가 정상 표시되는가?
- 2페이지, 3페이지를 추가할 수 있는가?
- 페이지 전환 후 각 페이지의 객체가 유지되는가?

## 객체

- 텍스트 추가/수정/삭제/복제가 되는가?
- 이미지 추가/교체/삭제/복제가 되는가?
- 동영상 추가/교체/재생/삭제가 되는가?
- 음악 추가/교체/재생/삭제가 되는가?
- 섹션 추가/크기 조절/삭제가 되는가?

## 직접 조작

- 객체를 드래그해 위치를 옮길 수 있는가?
- 객체 크기를 조절할 수 있는가?
- 객체가 캔버스 밖으로 과도하게 벗어나지 않는가?

## 저장/복원

- 저장 후 새로고침해도 객체가 유지되는가?
- 텍스트 내용과 스타일이 유지되는가?
- 이미지/동영상/음악이 유지되는가?

## 내보내기

- JSON 내보내기가 되는가?
- HTML 내보내기가 되는가?
- 내보낸 HTML이 브라우저에서 정상 표시되는가?

## 1뷰 기준

- 각 페이지가 스크롤 없이 한 번에 보이는가?
- 텍스트와 미디어가 서로 겹쳐 읽기 어렵지 않은가?
