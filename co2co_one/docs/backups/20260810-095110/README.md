# Co2Co 편집기 작업 운영 문서

이 폴더는 Co2Co 편집기 제작 과정에서 생기는 작업 계획, AI 팀 작업지시서, 고객용 매뉴얼, 검증 체크리스트를 보관합니다.

## 문서 구성

- `WORK_PLAN.md`: 현재 목표, 단계별 작업 계획, 우선순위
- `TEAM_BRIEF.md`: 코호와 AI 작업팀의 역할 및 공통 작업지시서
- `USER_MANUAL.md`: 고객이 편집기를 사용하는 방법
- `QA_CHECKLIST.md`: 기능 검증 항목과 테스트 기준
- `CHANGELOG.md`: 주요 변경 이력

## 운영 기준

- 중요한 기능을 추가하거나 구조를 바꿀 때는 먼저 작업 계획을 갱신합니다.
- 이미지, 텍스트, 음악, 동영상 작업은 필요한 경우 별도 작업지시서로 남깁니다.
- 고객이 직접 사용할 기능은 USER_MANUAL에 쉬운 말로 반영합니다.
- 큰 수정 후에는 QA_CHECKLIST 기준으로 확인합니다.
