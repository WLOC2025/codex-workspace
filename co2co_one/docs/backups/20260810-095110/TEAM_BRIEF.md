# Co2Co 편집기 팀 작업지시서

## 총괄 원칙

코호는 Co2Co 편집기 작업의 총괄 지휘자이자 최종 구현자이다. AI 팀은 각 전문 영역에서 계획, 제안, 검토, 검증을 수행하고, 코호가 결과를 통합해 `index.html`에 반영한다.

## 팀 구성

- 사용자: 총기획자 / 최종 승인자
- 코호: 총괄 디렉터 / 통합 제작자 / GitHub 반영 담당
- UX 설계 AI: 사용 흐름, 버튼 구조, 편집 패널 설계
- Visual Design AI: 시각 완성도, 레이아웃, 색상, 타이포그래피 설계
- ImageGen: 정적 이미지 제작
- Higgsfield: 동영상 및 모션 비주얼 제작
- Audio/Music AI: 음악 삽입 경험, BGM, 재생 UX 설계
- Frontend Engineer AI: 기능 구조와 구현 위험 검토
- State/Data AI: 객체 데이터, 저장, 복원, 내보내기 구조 설계
- QA AI: 실제 사용 시나리오 검증

## 공통 작업지시서

프로젝트명: Co2Co Editor

목표: 텍스트, 이미지, 음악, 동영상, 섹션, 블록을 사용자가 직접 넣고, 빼고, 이동하고, 크기를 조절하고, 내용을 변경할 수 있는 선도형 멀티미디어 홈페이지 편집기를 만든다.

기준:

- 1페이지는 스크롤 없는 1뷰를 의미한다.
- 필요하면 최대 3페이지까지 확장한다.
- 모든 객체는 선택 가능해야 한다.
- 모든 객체는 위치와 크기 조절이 가능해야 한다.
- 모든 미디어 객체는 교체 가능해야 한다.
- 편집기 UI는 고객이 쉽게 이해할 수 있어야 한다.
- 결과물은 고급 상업용 웹사이트 수준의 시각 품질을 지향한다.

## 작업 절차

1. 사용자 요청을 코호가 작업 목표로 정리한다.
2. 필요한 AI 팀원에게 역할별 작업지시서를 전달한다.
3. 코호가 결과를 통합해 구현 방향을 확정한다.
4. `index.html`을 수정한다.
5. QA 기준으로 확인한다.
6. 사용자 확인 후 GitHub에 반영한다.
