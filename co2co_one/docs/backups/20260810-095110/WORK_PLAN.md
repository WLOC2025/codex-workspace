# Co2Co 편집기 작업 계획

## 현재 목표

Co2Co 편집기를 텍스트, 이미지, 음악, 동영상, 섹션, 블록을 사용자가 직접 배치하고 조절할 수 있는 1~3페이지 멀티미디어 홈페이지 편집기로 발전시킨다.

## 핵심 기준

- 한 장면 = 한 페이지 = 스크롤 없이 한 번에 볼 수 있는 1뷰 화면
- 최대 3페이지까지 확장 가능
- 모든 객체는 추가, 선택, 이동, 크기 조절, 내용 변경, 복제, 삭제가 가능해야 한다.
- 초보자도 사용할 수 있어야 하고, 전문가도 세밀하게 조절할 수 있어야 한다.
- 결과물은 우선 `index.html` 단일 파일을 기준으로 한다.

## 현재 단계

- V1: 기본 1뷰 홈페이지 + 간단 편집 패널 구현 완료
- V2: 상태 기반 객체 편집기, 1~3페이지, 드래그/리사이즈 구조 1차 반영

## 다음 우선순위

1. V2 화면 사용성 점검
2. 객체 드래그/크기 조절 정확도 검증
3. 텍스트 직접 편집과 이동 기능 충돌 개선
4. 이미지/동영상/음악 저장 및 재로딩 안정화
5. HTML 내보내기 결과물 품질 개선
6. 고객용 사용 매뉴얼 보강
7. GitHub 반영 여부 결정

## V3 이후 우선 과제

1. 이전 저장 상태 초기화 버튼을 UI에 명확히 추가
2. 텍스트 편집 모드와 이동 모드 분리
3. 8방향 리사이즈 핸들 추가
4. 페이지 복제/삭제/재정렬 기능 추가
5. 레이어 앞으로/뒤로/맨뒤로 보내기 완성
6. 이미지 크롭/맞춤/채우기 제어 추가
7. 음악 객체의 제목, 반복, 볼륨, 표시 방식 제어 추가
8. HTML 내보내기의 시각 품질과 보안 이스케이프 개선

## V3.1 이후 우선 과제

1. 색상 변경이 모든 객체 유형에 더 정교하게 반영되도록 개선
2. 다중 선택 후 정렬/분배 기능 추가
3. 객체 간 거리 가이드와 스냅 라인 표시
4. 섹션을 움직이면 섹션 안의 객체들도 함께 움직이는 그룹/부모 구조 추가
5. 텍스트 편집 모드와 이동 모드 분리
6. 8방향 리사이즈 핸들 추가
