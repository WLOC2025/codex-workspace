# Co2Co 작업 이어가기

Co2Co 최신 기준 작업 파일은 `co2co_editor_v5.html`입니다. `co2co_editor_v3.html`, `co2co_editor_v4.html`과 이전 파일은 안전한 원본으로 보존합니다.

## 편집기 실행

YouTube 영상이 오류 153 없이 재생되도록 HTML 파일을 직접 더블클릭하지 말고 `run-co2co-editor.bat`를 실행합니다. 실행하면 `co2co_editor_v5.html`이 열립니다. 열려 있는 검은 실행창은 편집을 마칠 때 닫습니다.

## PC와 노트북 공통 작업 순서

1. 작업을 시작하기 전에 `E:\dev\codex\run-git-current-folder-app.bat`를 실행합니다.
2. 메뉴에서 `2. Start work: git pull`을 선택합니다.
3. `co2co_two\run-co2co-editor.bat`를 실행해 `co2co_editor_v5.html`에서 작업합니다.
4. 편집기 안의 **저장**은 현재 컴퓨터의 브라우저에 임시 저장할 때 사용합니다.
5. 다른 컴퓨터에서 같은 페이지 편집을 계속하려면 **프로젝트 저장**을 눌러 `.co2co` 파일을 이 폴더에 저장합니다. 저장 위치 선택창이 나오지 않으면 다운로드 폴더에 생긴 파일을 `co2co_two` 폴더로 옮깁니다.
6. 작업을 마치면 Git 앱 메뉴에서 `3. Finish work: add, commit, push`를 선택합니다.
7. 다른 컴퓨터에서는 다시 1~2번을 실행한 뒤 **프로젝트 열기**로 `.co2co` 파일을 엽니다.

## 버튼의 차이

- **저장 / 불러오기**: 현재 컴퓨터와 현재 브라우저에서 빠르게 이어 작업합니다.
- **프로젝트 저장 / 프로젝트 열기**: 편집 가능한 전체 상태를 PC와 노트북 사이에서 옮깁니다.
- **내보내기**: 방문자에게 공개할 완성 웹사이트 HTML을 만듭니다. 이 파일은 편집 프로젝트 파일과 용도가 다릅니다.

## v4 편집 모드와 레이어

- 오른쪽 설정창의 **기본 / 이미지 / 텍스트** 탭으로 필요한 조절 기능만 분리해서 봅니다.
- 모든 섹션과 블록에는 텍스트 편집 영역이 있으며, 이미지 블록의 텍스트는 이미지 위에 표시됩니다.
- **텍스트** 모드에서는 텍스트 입력·글꼴·크기·색상·굵기·줄 간격·정렬 조절만 표시됩니다.
- 상단 **레이어** 버튼을 누르면 포토샵 방식의 레이어 목록이 열립니다.
- 레이어 목록의 위쪽 항목이 캔버스에서도 가장 앞에 표시됩니다.
- 레이어를 끌어서 순서를 변경하고, 표시·숨김과 잠금, 이름 변경, 복제, 삭제를 할 수 있습니다.

## v5 이미지 전용 복층슬롯

- 기존 `레이어` 이미지 전환 블록의 이름을 **복층슬롯**으로 변경했습니다.
- 슬롯 1~5에 이미지를 넣고, 각 이미지를 변경하거나 삭제할 수 있습니다.
- 한 장만 넣어도 즉시 표시되고, 두 장 이상이면 설정한 간격으로 전환합니다.
- `3,1,5,2`처럼 직접 순서를 지정하거나 순차·랜덤 전환을 선택할 수 있습니다.
- 반복재생을 켜거나 끌 수 있습니다.
- 복층슬롯은 이미지 전용이며 음악과 동영상은 별도 블록을 사용합니다.

## v5 핵심 편집 동작

- 섹션·블록·이미지 블록을 포함한 모든 컴포넌트에서 **이미지** 탭으로 배경 이미지를 넣을 수 있습니다.
- 모든 컴포넌트에는 편집 가능한 텍스트 영역이 있습니다.
- 이미지와 텍스트가 함께 있으면 텍스트가 이미지보다 앞에 표시됩니다.
- 이미지 블록과 복층슬롯은 **이미지** 모드에서 이미지를 선택하고, **텍스트** 모드에서 위쪽 텍스트를 선택합니다.
- 캔버스에서 기존 이미지를 클릭하면 이미지를 다시 업로드하지 않고 이미지 편집창이 열립니다. 이미지 변경은 오른쪽 편집창의 버튼을 사용합니다.

## 충돌을 피하는 원칙

- 두 컴퓨터에서 동시에 같은 파일을 수정하지 않습니다.
- 시작할 때는 항상 Pull, 끝날 때는 항상 Commit + Push를 합니다.
- Git 앱에 수정 파일이 남아 있다고 나오면 Pull부터 하지 말고, 먼저 현재 작업을 Commit + Push합니다.
- `.co2co` 프로젝트 파일도 이 폴더 안에 두어야 GitHub를 통해 함께 전달됩니다.

## 제품 방향

Co2Co는 초보자도 상업용 웹사이트의 모든 구성요소를 캔버스 위에서 직접 배치하고, 전체 테마와 정렬처럼 서로 연결된 설정을 한 번에 바꿀 수 있게 하는 것을 목표로 합니다. 새 기능은 사용하기 쉬움, 전체 일관성, 되돌릴 수 있음, PC·노트북 간 연속성을 우선합니다.
