## 요청 내용

Codex에서 생긴 사용자 요청사항과 사용자 피드백은 `E:\dev\codex` 안의 전용 폴더에만 기록한다.

## 기준 폴더

- 사용자 요청사항: `E:\dev\codex\사용자 요청사항(지침,기억)`
- 사용자 피드백: `E:\dev\codex\사용자 피드백(건의,제안)`

## 운영 원칙

- 사용자 요청사항은 사용자 요청사항 폴더에 기록한다.
- 사용자 피드백은 사용자 피드백 폴더에 기록한다.
- 단순하게 `E:\dev\codex`의 두 폴더만 기준으로 삼는다.
