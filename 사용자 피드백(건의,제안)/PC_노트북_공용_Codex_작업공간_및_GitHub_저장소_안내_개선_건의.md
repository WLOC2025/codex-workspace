# PC·노트북 공용 Codex 작업공간 및 GitHub 저장소 안내 개선 건의

- **기록일**: 2026-08-17
- **구분**: 사용자 피드백 / 건의 / 제안
- **상태**: 아이디어
- **우선순위**: 보통

## 건의 원문

피씨와 노트북을 사용하는 고객들이 `E:\dev\codex`와 같은 폴더를 공용으로 이용하여 작업할 수 있도록 하고, `https://github.com/WLOC250801/codex-workspace.git` 와 같은 리포지토리를 공용으로 이용하여 폴더와 파일을 관리할 수 있도록 안내 해주면 좋겠습니다.

## 배경

- 여러 기기에서 Codex를 사용할 때 작업 파일 위치가 흩어지면 프로젝트 관리가 어려워질 수 있다.
- OneDrive 같은 자동 동기화 폴더를 개발 작업공간으로 쓰면 사용자가 원하지 않는 업로드, 경로 혼동, 동기화 충돌이 생길 수 있다.
- 공유 가능한 `E:\dev\codex` 작업 루트와 GitHub 저장소를 함께 안내하면 작업 연속성과 파일 관리가 좋아질 수 있다.

## 원하는 개선

- Codex 사용 안내 또는 초기 설정 가이드에서 PC·노트북을 함께 쓰는 사용자를 위한 공용 작업공간 구성 예시를 제공한다.
- 예시 경로로 `E:\dev\codex` 같은 공유 드라이브 작업 루트를 안내한다.
- 예시 저장소로 `https://github.com/WLOC250801/codex-workspace.git` 같은 GitHub 리포지토리를 공용 프로젝트 관리 저장소로 활용하는 방법을 안내한다.
- 로컬 작업 폴더, 공유 드라이브, GitHub 저장소의 역할을 구분해서 설명한다.

## 기대 효과

- PC와 노트북에서 같은 프로젝트를 안정적으로 이어서 작업할 수 있다.
- 사용자가 파일 위치를 직접 통제하면서 GitHub로 변경 이력을 관리할 수 있다.
- OneDrive 자동 관리 폴더 사용으로 인한 혼란을 줄일 수 있다.
- Codex 초보 사용자도 로컬 작업 폴더, 공유 드라이브, GitHub 저장소의 관계를 쉽게 이해할 수 있다.
