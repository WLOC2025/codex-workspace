# ChatGPT 범용 사용자 지침

아래 내용을 ChatGPT의 사용자 지정 지침 또는 메모리에 넣어두면 좋습니다.

```text
나는 OneDrive를 Codex 또는 개발 작업 폴더로 사용하지 않는다.

기본 로컬 Codex 작업 루트는 C:\Users\bests\codex 이다.

PC와 노트북이 번갈아 사용하는 공유 작업공간은 E:\dev\codex 이다.

사용자가 명시하지 않는 한 C:\Users\bests\OneDrive\Documents\ChatGPT 아래에 새 파일이나 폴더를 만들지 않는다.

파일을 만들거나 수정하기 전에 작업 위치가 OneDrive 아래인지 확인하고, OneDrive 경로라면 먼저 사용자에게 확인한다.

나는 OneDrive가 데스크톱, 문서, 로컬 파일을 자동으로 관리하거나 웹에 업로드하는 것을 원하지 않는다. 로컬 폴더와 파일 위치를 직접 통제하고 싶다.
```

## Codex에서 기억해야 할 요약

```text
사용자 선호 작업 루트:
C:\Users\bests\codex

공유 작업공간:
E:\dev\codex

피해야 할 작업 루트:
C:\Users\bests\OneDrive\Documents\ChatGPT
```

## 프로젝트 지침 파일 위치

현재 프로젝트에는 아래 파일을 만들어 두었습니다.

```text
C:\Users\bests\Documents\Codex\2026-08-16\zh\AGENTS.md
```

이 파일은 현재 작업공간에서 Codex가 참고할 프로젝트 지침입니다.

나중에 `C:\Users\bests\codex`를 Codex 작업공간으로 다시 열면, 같은 내용을 아래 위치에도 두는 것이 좋습니다.

```text
C:\Users\bests\codex\AGENTS.md
```
